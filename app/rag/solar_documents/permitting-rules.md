# Permitting process notes for photovoltaic development

Permitting is a sequence of applications, notices, and conditions, not a
single overlay. This note describes that sequence at a methodological level
so answers about process stay grounded. It does not grant or refuse a permit
for any site.

## Typical process stages

Developers commonly move from land-rights and zoning checks, through
environmental screening, to building or works permission, and then to grid
connection offers and generating-licence steps where those exist. Rooftop
projects often follow a shorter path than utility-scale plants, but they still
meet electrical and building rules. The order varies by jurisdiction. This
corpus records the existence of stages, not a statutory deadline.

## Relating process to a site question

If the user asks what permitting rules affect a site, describe the stages that
match the project type and say that the competent authority confirms which
stage is active. If SolarDSS recorded a land-use or protected-area screen,
report that screen as analytical evidence and use this note only to explain
why such a screen appears in a permitting path.

## Evidence partition

Process language retrieved here is knowledge and document evidence. A
configured exclusion, a missing-requirement slot, or a provider-filled layer
from SolarDSS is deterministic analytical evidence. Never fill a missing
permit status by quoting this narrative as if it were a decision.
