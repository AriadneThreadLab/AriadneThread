# Technical standards used in photovoltaic projects

Photovoltaic projects reference consensus standards for modules, arrays,
converters, and resource assessment vocabulary. This note names the role of
those standards. It does not reproduce normative numeric limits and it is not
a substitute for purchasing or citing the standard text itself.

## Families of standards

Design-qualification and safety standards address module durability and shock
protection. Array standards address installation design. Converter standards
address grid interface behaviour. Resource-assessment guides define quantities
such as global horizontal irradiance conceptually. A language model may use
this note to say which family is relevant. It may not treat the note as the
standard.

## Use in explanations

When a user asks which technical standard matters, point to the family that
matches the question: product qualification, array design, or grid code
implementation. Then cite the public standards body attached to this document.
Site-specific compliance remains an engineering determination.

## What RAG must not do with standards

Do not extract tabulated limits, test voltages, or climatic sequence
parameters from memory and present them as retrieved evidence. Do not use a
standard identifier as if it were a SolarDSS indicator. Keep computed site
metrics in the analytical evidence partition.
